# 碳中和园 · 校园低碳养成

一个以「低碳行为可视化 + 植物养成」为核心的校园主题网页小游戏。
纯 HTML / CSS / JavaScript，**零依赖、零构建**，竖屏 1080×1920 设计，任意屏幕等比缩放。

> 竞赛作品 · 可玩垂直切片

---

## 玩法

```
校园行走               农场经营
选任务 → 算减排         选种子 → 种植
双账户分别入账          浇水/施肥 → 长大
成长值 → 植物进阶       收获 → 背包 → 出售
```

### 两套场景

| 场景 | 内容 |
|---|---|
| **校园地图** | 3/4 俯视可行走地图，A* 点击寻路，走近建筑进入对应功能 |
| **农场** | 16 块地，3 种作物 × 5 个生长阶段，点地块弹信息、底栏操作 |

### 核心机制

- **双账户隔离**：碳账本（只读，只进不出）与游戏资源（可流转）物理分离
- **可验算的减排**：`估算减排量 = 数量 ×（基准因子 − 实际因子）`，界面展示完整计算情景
- **无时间惩罚**：作物不按真实时间生长，浇水/施肥即刻推进阶段

## 本地运行

```bash
cd web
python serve.py 8791
```

打开 `http://127.0.0.1:8791/`

> ⚠️ 不要用 `python -m http.server`：它不认识 `.webp`，会发错 Content-Type，导致 Canvas 加载失败。

## 目录结构

```
.
├─ web/                源码（可直接运行）
│  ├─ index.html
│  ├─ app.js           状态 + 界面 + 玩法逻辑
│  ├─ world.js         校园行走引擎（碰撞 / A* 寻路 / 八方向动画）
│  ├─ data.js          ★ 所有数值：因子 / 任务 / 作物 / 等级
│  ├─ styles.css
│  ├─ serve.py         本地服务器（正确 MIME）
│  └─ assets/          图片素材
├─ dist/               构建产物（可直接部署，Cloudflare Pages 上传这个）
└─ Collab/             设计文档、契约、美术参考、开发日志
```

**所有数值都在 `web/data.js`**，改平衡不需要碰代码。

## 部署

`dist/` 是可直接上传的静态站点（约 3 MB），支持 Cloudflare Pages / Vercel / 任意静态服务器。

```bash
# Cloudflare Pages：直接上传 dist 目录内容
# 或命令行
npx wrangler pages deploy dist --project-name lowcarbon-campus
```

## 技术要点

| 项 | 做法 |
|---|---|
| 渲染 | Canvas（校园）+ DOM（UI），无引擎、无框架 |
| 碰撞 | PNG 掩码逐像素采样（`assets/collide.png`，白=可走） |
| 寻路 | 掩码转 4px 网格 → A*（8 邻接、禁穿墙角）→ 拐点简化 |
| 动画 | 8 方向 × 8 帧图集（`hero8.webp`），11fps |
| 存档 | `localStorage`，版本号不匹配时丢弃而不是崩溃 |

## 开发备忘

- 农场那段 CSS 位于 `styles.css` **最前面**（放到末尾会失效，原因未定位）
- 调试参数：
  - `?debug=1` 碰撞层 + 帧数 + 坐标
  - `?selftest=1` 四方向可走距离自检
  - `?pathto=dorm` 直接规划到某个门的路线
  - `?screen=garden&demo=1` 直达农场并预置数据
