# 30_Art —— 视觉设定

ChatGPT 出方案，我落地成 Unity 资源。

## 建议的三个文件

| 文件 | 内容 |
|---|---|
| `palette.md` | 色板，键名 lowerCamelCase + hex，工程端直接照抄。例如 `primaryGreen: #3FA76B` |
| `mockups/` | 线框图。截图或手绘都行，命名 `YYYY-MM-DD-屏幕名.png` |
| `prompts.md` | 生图提示词，一条一个资源，标明用途和尺寸 |

## 给 ChatGPT 的硬要求

色值必须给 **hex**，不许给"清新一点的绿"这种描述。工程端没法把形容词变成 `Color`。

配色也不要超过 6 个主色。低碳主题容易做成一整片绿，那会很难读——**绿色留给"减排量"这一个语义**，其他用中性灰和留白。

## 授权注意

竞赛要提交作品，素材版权会被查。免费素材站要记下来源和许可证（CC0 / CC-BY），写进 `prompts.md` 或单独一列。AI 生图也要注明。
