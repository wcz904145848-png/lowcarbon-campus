# 任务卡模板

复制这个骨架写新卡，存成 `to-gpt/T-00x-简述.md`。

写作要点：

- **一次只问一件事的闭包。** 一张卡如果能让 ChatGPT 回出 5000 字，就说明它太大了。
- **写清验收标准。** 「我读完能直接生成 X 并跑起来，不用再问你」——这句是所有卡片的隐藏目标。
- **附上契约。** 不附，它就开始发明词汇。
- **标出禁区。** 明确说「这轮不要碰什么」，比说「请做这轮」更能防跑偏。

---

```markdown
# T-00x <标题>

> 发出时间：YYYY-MM-DD ｜ 契约版本：0.1.1 ｜ 上一轮：T-00(x-1)

## 背景（30 秒能读完）
<我现在手上有什么，卡在哪，为什么需要你>

## 我要你产出什么（按顺序）
1. …
2. …

## 约束
- 契约里已冻结的部分不许改，字段名照抄。
- 这轮**不要**碰：<比如：UI 配色、第二关、音效>。

## 输出格式
按常驻规则：YAML 头 + 编号小节 + 表格。

## 验收标准（我拿它干什么）
- [ ] 我能直接生成 `Assets/GameData/xxx.json` 并跑通
- [ ] 不需要再回问你任何一次
- [ ] 数值算一遍是自洽的

## 你可能想提的契约变更
（如果你觉得字段不够用，单独一节写提案，不要偷偷加字段）
```
