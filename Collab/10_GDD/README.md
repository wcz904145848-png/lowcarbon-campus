# 10_GDD —— 设计文档

ChatGPT 写，你存进来。命名：`YYYY-MM-DD-T-00x-简述.md`。

## 只放这些

- 玩法规则（一页能读完的那种）
- 关卡结构
- 数值表（也同时落成 `Assets/GameData/*.json`，md 只是给人读的副本）
- 系统说明（比如「行动解锁」怎么算）

## 不放这些

- C# 代码 → 我写
- 实现步骤 / Unity 操作指引 → 我判断
- 「我们也许可以……」的头脑风暴 → 那种东西进 `50_DECISIONS.md` 的候选，或者干脆丢掉

## 一条纪律

**GDD 是副本，不是真相。** 数值的真相在 `Assets/GameData/*.json` 里。两者冲突时，以 JSON 为准，然后回来改 GDD——不要反过来。
